# Vesper

A quiet personal tracker for habits, mood, and the shape of your days.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:8080](http://localhost:8080).

- **Download the app** from Settings on your phone. The mark is a white V on black.
- Data stays in this browser until you export it from Settings.

## Build

```bash
npm run build
```
